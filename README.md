# 📝 Wish To Do List

Uma aplicação web moderna para **organizar tarefas e desejos do dia a dia**.  
O projeto foi desenvolvido utilizando **React e TypeScript**, proporcionando uma interface dinâmica, tipagem segura e melhor organização do código.

🌐 **Live Demo:**  
https://babxlims.github.io/wish-to-do-list/

---

# 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido com as seguintes tecnologias:

- ⚛️ React
- 🔷 TypeScript
- 🎨 CSS3
- 🌐 HTML5
- ⚡ Vite

---

# ✨ Funcionalidades

- ➕ Adicionar novas tarefas
- ✅ Marcar tarefas como concluídas
- ❌ Remover tarefas
- 📋 Organizar atividades do dia a dia
- ⚡ Interface rápida e interativa
- 📱 Layout simples e responsivo

# 💻 Como Executar o Projeto

### 1️⃣ Clone o repositório

```
git clone https://github.com/babxlims/wish-to-do-list.git
```

### 2️⃣ Entre na pasta do projeto

```
cd wish-to-do-list
```

### 3️⃣ Instale as dependências

```
npm install
```

### 4️⃣ Execute o projeto

```
npm run dev
```

Depois abra no navegador:

```
http://localhost:5173
```
